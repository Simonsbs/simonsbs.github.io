04 / ENGINEERING JUDGEMENT

Why it works this way.

Evidence before generation

Public evidence mode quotes canonical passages and runs entirely in the browser. It is useful without a model account or a hosted inference service.

Server-owned context admission

The optional loopback Python adapter reloads the canonical pack, applies its own role and validates admitted context before calling Ollama.

Keep measured claims bounded

The synthetic cases expose regressions and model errors. Passing them does not establish general accuracy or independent human acceptance.

05 / INSPECT THE EVIDENCE

Tested behaviour.
Explicit limits.

  • 68 recorded retrieval/pipeline cases and 46 generated-answer content checks pass in the accepted local Qwen3 8B run.

  • Seven invalid-context probes are rejected. Earlier retrieval and model failures remain in the repository.

  • Source-linked agent review and reproducible setup are published with the project.

Read the recorded validation

Scope of this project

All company policies and records are synthetic. Browser role filtering over a public pack is a simulation, not private-data protection.

The public demo does not run hosted model inference. Ollama runs only in the optional local checkout.

Both labelled sets are agent-authored regression coverage. Version 1 was accepted on agent validation; human review is not claimed.
