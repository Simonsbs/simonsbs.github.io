Private by design

Data safety summary

A clear summary of the answers used for Math For Maya's Google Play Data safety declaration.

Applies to: Math For Maya for Android

None

Data collected

The app does not collect or transmit required user data types.

None

Data shared

The app does not share user data with BestDev or third parties.

No account

Account deletion

There is no account, login or developer-held profile to delete.

Offline

Network use

Maths practice runs on the device without an internet connection.

Implementation basis

  • No account or sign-in system
  • No analytics or crash-reporting SDK
  • No advertising SDK
  • No in-app purchases or subscriptions
  • No cloud sync, remote database or user-generated content
  • No location, camera, microphone, contacts, photos, files or health-data access
  • Applause plays from an audio file bundled inside the app
  • Exercise choices and answers are used only during the active app session

Encryption in transit: Not applicable because the app does not transmit user data.

Children and families

The app is intended for children ages 6 to 8. It contains child-friendly educational content and no ads, purchases, in-app communication, social features or personal data collection. Optional information and support links open BestDev's Math For Maya website in the device browser.

Keeping this summary accurate

BestDev will reassess this declaration before releasing any version that adds analytics, advertising, accounts, cloud features, new permissions or a new third-party SDK.
